# v0.4.0 发布说明

**发布日期**：2026-10-06
**许可证**：Apache License 2.0
**系统要求**：Android 8.0（API 26）及以上，arm64-v8a

---

## 这个版本是什么

**首个正式发布版。** 从 2026-09-23 的第一个能装的 APK 到今天，功能与工程质量都做过一轮完整收敛。

一句话介绍：**完全离线的 Android 听书 App**——导入本地 EPUB / PDF / TXT，
用装在手机里的神经网络语音引擎按章节朗读，全程不联网。

---

## 三个发布包

| 包 | 体积 | 说明 |
|---|---|---|
| **Full** | 180.6 MB | **推荐**。模型内置，开箱即用 |
| **Lite** | 42.1 MB | 不含模型。首次使用在 App 里点「选择模型文件夹」导入 |

两个包**可以同时安装**（包名不同：`top.readaloud.app` / `top.readaloud.app.lite`），
包名不同意味着它们可以互相独立存在、互不干扰。

## 能做什么

- **格式**：TXT / EPUB（EPUB2、EPUB3）/ PDF（需文字层）
- **目录**：EPUB 读书内目录；PDF 三级降级——内嵌书签 → 目录页重建 → 按字号认标题
- **朗读**：离线神经网络 TTS，103 个音色，默认中文女声（音色 #3）
- **读音**：正文归一化（数字、日期、百分比、单位转中文读法）+ 96 条多音字纠正词典（可关闭）
- **节奏**：三档停顿、0.6–2.0 倍速、点任意一句从那一句开始、高亮实时跟随
- **后台**：锁屏继续播、通知栏控制、耳机/蓝牙线控、睡眠定时（按分钟 / 念完本章后停）
- **书架**：多本书管理、进度自动保存、换书互不干扰

## 为什么值得用（和别的听书 App 不一样）

**你的书不会离开你的手机。**

这不是一句宣传语，而是**操作系统级别的保证**：这个 App 的安装包里
**没有声明 `android.permission.INTERNET` 权限**，安卓系统据此直接禁止它创建任何网络连接。
任何人都可以自己验证：

```bash
apkanalyzer manifest permissions 阅听-v0.4.0-release-正式签名版.apk
# 输出里没有 INTERNET，也没有 ACCESS_NETWORK_STATE
```

所以：涉密资料、内部文档、未公开的稿件，都可以放心用它读。

## 已知限制

诚实列出来，免得踩坑：

- PDF 必须是**有文字层**的（能选中文字）。扫描影印版无法朗读，会明确提示
- EPUB 的复杂排版（脚注、多栏）按纯文本流处理，个别地方顺序可能不准
- 中文发音依赖 Kokoro 词表（20901 字），生僻字可能读错（会写进日志）
- 合成速度约实时的 1/3（麒麟 710F 上每段 10~20 秒），长章节首段等待较久
- 英文与其他语种的发音依赖 espeak-ng 数据，受其 GPL-3.0 许可限制（详见下方"许可"）

## 从源码构建

```bash
git clone <仓库地址>
cd Readaloud

# 第一步：下载模型（约 200MB；仓库里没有 —— model.int8.onnx 有 109MB，
#         超过 GitHub 单文件 100MB 的硬限制）。脚本走国内镜像，不需要梯子。
python tools/fetch_model.py

# 第二步：编译
./gradlew.bat assembleFullDebug        # 调试包，约 1 分钟
./gradlew.bat assembleFullRelease      # 正式包（需签名），约 5~7 分钟
```

只编 Lite 变体可以跳过模型下载。

## 参与贡献

欢迎提 Issue 和 PR。几条约定（都是踩过坑才定下来的，改之前请先读）：

1. **读文件必须走 `BookReader.load()`** —— 界面与播放服务共用它，保证两边切分一致
2. **播放位置与目录的决策权在服务端** —— 界面读不准播放器的瞬时状态
3. **AGP 9 必须显式声明变体 assets**，否则 200MB 模型不会打进 APK（编译却全绿）
4. **改完 R8 规则要跑真机回归**：`python tools/regress_r8.py`
   （编译成功不代表能用——出问题的特点是"能启动、一用就崩"）
