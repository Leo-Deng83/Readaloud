**发布日期**：2026-10-07

## 这一版做了什么

v0.4.0 是第一个能用的正式版，这一版把它补成了"日常真的用得顺"的版本——
**三个新功能 + 修掉两个隐蔽 bug**。

### 🆕 目录页（独立一页）

之前章节是「正在听」页顶部一根**横向**条子，只能左右滑、一眼看不全，章节一多就挤成一条细缝。

现在底部多了一个**「目录」页签**：

- 竖排全书章节，**完整标题**（最多两行）
- **正在读的那一章高亮**，一眼看出读到哪儿了
- 点章节 → 直接跳过去，并**自动回到正文页**
- 没识别到章节时明确说明原因（PDF 换个文件、TXT 换个写法）

### 🆕 书签

- 正文页播放控件旁多一个**「收藏」**按钮——听到有意思的地方随手一点（再点取消）
- 目录页第二个分段集中管理：点一条跳回那句话，**长按删除**（有确认框）
- 每条显示**时间 + 那句话的原文**
- **关掉 App 再打开书签还在**（已实测：杀进程重启后数据仍在）

### 🆕 正文排版（设置页）

| 项 | 可选 |
|---|---|
| **字体** | 下拉菜单：系统默认 / 宋体 / 等宽 + **可导入自己的 ttf / otf** |
| **字号** | **滑条 1~99 sp** 连续调节（Apple 风格：细轨道 + 白圆钮 + 每档震感） |
| **配色** | 跟随系统 / 日间 / **米黄（护眼）** / **夜间**，铺满整个页面 |

> **关于字体**：手机系统里只装了黑体和宋体两种中文字体（实测荣耀 9X），
> **没有楷体、仿宋、圆体**。与其列一堆"点了没变化"的选项，不如给你导入入口——
> 把字体文件拷到手机，在设置里点「＋ 导入字体文件」即可，想要什么字体就有什么。
> 字体只存在你自己手机里，App 不打包任何字体，也不涉及授权问题。

### 🐛 修掉的两个隐蔽 bug

**1. 换书后还在播旧书（严重）**

从正在读的书换到另一本 → 界面显示新书，**声音还在放旧书**；点暂停再"继续"又是旧书。
更糟的是它会把**旧书的进度写进新书的记录**，两本书互相污染。

修法：界面载入新书时通知后台"换书了"，后台作废当前这一轮合成并暂停；
界面侧记录"当前队列属于哪本书"，四处入口（继续 / 上一句 / 下一句 / 点句）都先核对。

**2. PDF 目录只认得出 1/6 个章节**

排序方向搞反了，导致"游标只向后"的定位逻辑一开头就跑到文末，后面全失败。
改成升序后 6 个章节全部正确；顺带修好了「1. 数据抽取」这类标题的落点偏移。

## 两个安装包

| 包 | 体积 | 说明 |
|---|---|---|
| **Full** | ~180 MB | **推荐**。模型内置，开箱即用 |
| **Lite** | ~42 MB | 不含模型。首次用本地引擎时点「选择模型文件夹」导入 |

包名不同（`top.readaloud.app` / `top.readaloud.app.lite`），**可以同时安装**。

## 为什么值得用

**你的书不会离开你的手机。** 这不是宣传语——安装包里**没有声明
`android.permission.INTERNET` 权限**，安卓系统据此直接禁止它创建任何网络连接。
任何人都可以用 `apkanalyzer manifest permissions` 自己验证。

## 已知限制

- PDF 必须**有文字层**（能选中文字），扫描影印版无法朗读
- EPUB 的复杂排版（脚注、多栏）按纯文本流处理，个别地方顺序可能不准
- 中文发音依赖 Kokoro 词表（20901 字），生僻字可能读错（会写进日志）
- 合成速度约实时的 1/3（麒麟 710F 上每段 10~20 秒），长章节首段等待较久
- 英文与其他语种依赖 espeak-ng 数据，受其 GPL-3.0 许可限制
  （详见 `docs/第三方组件与许可证.md`，开源分发不受影响）

## 从源码构建

```bash
python tools/fetch_model.py        # 下载模型（约 200MB，仓库里没有）
./gradlew.bat assembleFullRelease  # 需要签名凭据，见 docs/发布签名说明.md
```

## 参与贡献

欢迎提 Issue 和 PR。四条约定（都是踩过坑才定下来的）：

1. **读文件必须走 `BookReader.load()`** —— 界面与播放服务共用它，保证两边切分一致
2. **播放位置与目录的决策权在服务端** —— 界面读不准播放器的瞬时状态
3. **AGP 9 必须显式声明变体 assets**，否则 200MB 模型不会打进 APK（编译却全绿）
4. **改完 R8 规则要跑真机回归**：`python tools/regress_r8.py`
   （编译成功不代表能用——出问题的特点是"能启动、一用就崩"）
